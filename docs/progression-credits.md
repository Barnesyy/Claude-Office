# Progression sprites: credits

Drawn for this fork by `scripts/generate-progression-sprites.py`, in the upstream
Claude-Office sprite style (hi-bit pixel art, 1 px navy outline, cel shading).

| Sprite | Source | Licence |
| --- | --- | --- |
| trophy-cabinet, mailbox-up, mailbox-down, shipped-bin, parcel, planter, plant-0..3, lessons-binder, dust-sheet-*, padlock | Drawn here (PIL polygons on an isometric grid) | MIT, with this repository |
| trophy-bronze, trophy-silver, trophy-gold, trophy-platinum | Pixor library "trophy-small", re-toned per tier, outlined and contrast-lifted | CC0 1.0 (Pixor, https://pixor.art/library/license/) |
| medal, crown, clover, gem | Pixor library "medal", "crown", "four-leaf-clover", "gem", outlined and contrast-lifted | CC0 1.0 (Pixor) |

Some assets from the Pixor library (https://pixor.art/library/). CC0 asks for no
attribution; it is given anyway.

The room also reuses upstream's own MIT sprites, unchanged:
`/sprites/rooms/server-rack-2.webp` (backtest bay), `/sprites/decoration/money-tree.png`,
`/sprites/trading/props/equity-curve-frame.png`, `/sprites/trading/props/bull-trophy.png`
(the rare golden bull), `/sprites/effects/star.png` and `/sprites/effects/party.png`
(the unlock star burst).

No Dunder Mifflin or other third-party trademarked art is used.
